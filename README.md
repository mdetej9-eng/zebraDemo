# Парикмахерская «Зебра» — сайт-визитка

Одностраничный сайт-визитка для парикмахерской «Зебра» (г. Ставрополь, ул. Ленина, 452/а).

> ⚠️ **МАЛО ФОТО**: в проекте всего 1 фото (вход). Галерея работ — заглушка «скоро». Нужна фотосъёмка.

## Стиль

Editorial dark («зебра»): графитовый фон, красный акцент вывески, шрифты Unbounded + Manrope. Сплит-герой, нумерованные списки услуг, крупный контактный блок.

## Что внутри

- **Плашка «Демо-концепт»** в углу — сайт сделан заранее для презентации
- **Сплит-герой** с фото входа и чипами
- **Услуги** — нумерованные строки 01–03: парикмахерский зал, маникюр/педикюр, наращивание
- **О салоне** — текст + статистика + ссылка на 2ГИС
- **Работы** — заглушка до фотосъёмки
- **Контакты**: большой тел.-блок, адрес, отзывы

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей.

## Как добавить фото работ

Положить файлы в `img/` как `work-01.jpg … work-08.jpg`, заменить `.gallery__empty` на сетку `.gallery__grid` по образцу сайта «Весна» и добавить разметку лайтбокса (js/main.js уже поддерживает).
